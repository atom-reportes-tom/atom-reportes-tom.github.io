Política de privacidad — ATOM lector

Qué es

ATOM lector es una herramienta personal y privada. La usa una sola persona, su dueño, con una única cuenta de Gmail creada para este fin. No está disponible para otros usuarios.

Qué datos usa

  • Lee los mensajes y archivos adjuntos de esa única casilla con el permiso de Google gmail.readonly (solo lectura).
  • No envía, responde, modifica ni borra correos.
  • No accede a ninguna otra cuenta de Google.

Dónde se guardan

Los adjuntos se guardan solo en un servidor privado del dueño, sin acceso desde internet. No se comparten, venden ni transfieren a terceros, y no se usan para publicidad.

Cómo revocar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.

Uso de datos de las APIs de Google

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de las APIs de Google, incluidos los requisitos de uso limitado.

Contacto

atom.reportes.tom@gmail.com

English summary. ATOM lector is a private, single-user tool. It reads one dedicated Gmail mailbox with the read-only gmail.readonly scope, never sends or deletes email, stores attachments only on the owner's private server, and does not share data with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
